# Сторож формы на Timeweb

## Рекомендуемый способ: PHP CLI (без curl и без секрета в команде)

Скрипт `form-watch-cron.php` в режиме CLI читает `config.php` из той же папки `api/` — секрет в cron-строку не подставляется.

### 1. Узнать полный путь к файлу на сервере

1. [timeweb.com](https://timeweb.com) → **Хостинг** → **Сайты**.
2. Сайт **morozovanatalia.ru** → **Файловый менеджер** (или **Настройки** / **Корневая папка**).
3. Скопируйте **абсолютный путь к `public_html`** (у Timeweb часто виден вверху менеджера или в настройках сайта), например:
   - `/home/u/1234567/morozovanatalia.ru/public_html`
   - или `/home/u/1234567/domains/morozovanatalia.ru/public_html`

Полный путь к сторожу:

```text
<КОРЕНЬ_САЙТА>/api/form-watch-cron.php
```

Пример (подставьте свой корень из панели):

```text
/home/u/1234567/morozovanatalia.ru/public_html/api/form-watch-cron.php
```

Проверка: в файловом менеджере файл лежит в `public_html/api/form-watch-cron.php`.

### 2. Путь к PHP CLI

В той же панели Timeweb при создании cron для типа **«Выполнить PHP-скрипт»** версию PHP обычно выбирают из списка (8.1 / 8.2 / 8.3).

Если нужна **команда вручную** (тип «Выполнить команду» / shell):

1. **Хостинг** → **Сайты** → **PHP** (версия для сайта) — запомните версию (например 8.2).
2. Типичные бинарники на Timeweb:
   - `/usr/bin/php`
   - `/opt/php/8.2/bin/php` (цифра = ваша версия)

Точный путь без догадок: в **Планировщике** при создании задачи **«PHP-скрипт»** панель сама подставляет интерпретатор — тогда в поле «Путь к скрипту» укажите только файл из п.1.

### 3. Добавить задачу в планировщик

1. **Хостинг** → **Планировщик заданий** (Cron).
2. **Создать задачу**.

**Вариант A — «Выполнить PHP-скрипт» (предпочтительно):**

| Поле | Значение |
|------|----------|
| Периодичность | Каждые 10 минут (`*/10 * * * *`) |
| PHP | Версия как у сайта (8.1+) |
| Путь к скрипту | `/home/u/…/public_html/api/form-watch-cron.php` |

**Вариант B — «Выполнить команду»:**

```bash
/opt/php/8.2/bin/php /home/u/1234567/morozovanatalia.ru/public_html/api/form-watch-cron.php >> /home/u/1234567/morozovanatalia.ru/public_html/api/data/form-watch-cron.log 2>&1
```

Замените пути на свои. Секрет в команде **не нужен**.

Расписание cron: **минуты** `*/10`, остальные поля `*`.

### 4. Проверить, что задача отработала

1. В планировщике нажмите **«Выполнить сейчас»** (если есть).
2. **Файловый менеджер** → `public_html/api/data/form-watch-state.json` — время изменения должно обновиться.
3. При ошибках health в MAX придёт «⚠️ Сбой формы: health FAIL…» (не чаще раза в час).
4. В **21:00 МСК** (первый запуск в час 21) — короткий отчёт «Форма жива, заявок за сутки: N».
5. Публично: `https://www.morozovanatalia.ru/api/health.php` → `"ok": true`.

Лог (если добавили `>> …/api/data/form-watch-cron.log`; каталог `data/` закрыт от веба): последняя строка JSON с `"ok": true` и `"sent": []` или `"daily_report"` / `"alert_down"`.

## Альтернатива: HTTP + curl

См. историческую схему с заголовком `X-Morozova-Internal-Secret` — для CLI не требуется.

## Публичный health

`https://www.morozovanatalia.ru/api/health.php` — без секретов в ответе.

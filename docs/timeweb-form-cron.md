# Сторож формы на Timeweb

В репозитории **нет** доступа к панели Timeweb — cron настраивается вручную один раз.

## Где в Timeweb

1. Панель хостинга → сайт **morozovanatalia.ru**
2. Раздел **«Планировщик заданий»** / **Cron** (название может отличаться в версии панели)
3. Добавить задание **каждые 10 минут**

## Команда (HTTP)

Подставьте `INTERNAL_API_SECRET` из локального `amocrm.secrets.env` (не коммитить):

```bash
*/10 * * * * curl -fsS -o /dev/null -H "X-Morozova-Internal-Secret: ВАШ_СЕКРЕТ" "https://www.morozovanatalia.ru/api/form-watch-cron.php" || true
```

Альтернатива в панели Timeweb — тип задания **«Обращение к URL»** с тем же URL и заголовком (если панель поддерживает custom headers; иначе только через SSH/cron на VPS — на shared обычно достаточно curl в cron).

## Что делает `form-watch-cron.php`

- Вызывает те же проверки, что `health.php`
- При сбое — одно сообщение в MAX **не чаще раза в час**
- При восстановлении — «форма снова в норме»
- В **21:00 МСК** (первый вызов в час 21) — «Форма жива, заявок за сутки: N»; если три дня подряд N=0 — дополнительная пометка

Состояние (антиспам) хранится в `api/data/form-watch-state.json` (каталог закрыт от веба).

## Публичный health (без секретов)

`https://www.morozovanatalia.ru/api/health.php` — JSON `ok` + список проверок, без токенов и паролей.
